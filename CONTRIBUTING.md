# 🤝 Contributing to Animating Buttons

Thank you for contributing! This project is part of **GSSoC 2026**.

## 🚀 Quick Start

1. **Fork** and **clone**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Animating-Buttons.git
   ```
2. **Branch**: `git checkout -b add/my-button`
3. **Add button** in `buttons/YourName_ButtonName/` (index.html + style.css)
4. **Update** `data.js`
5. **Commit & push**: `git commit -m "feat: Add button"`
6. **Open PR**

## ✅ Guidelines
- Unique button (no duplicates)
- CSS transforms for smooth animations
- Responsive design
- Conventional commits (`feat:`, `fix:`, `docs:`)
